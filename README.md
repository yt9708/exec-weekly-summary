# 高管周总结系统 · Exec Weekly Summary

> 让中高层管理者 **10 分钟内** 完成每周信息消化与决策确认

**用户端**：https://exec-weekly-summary.bonto.run/  
**管理后台**：https://exec-weekly-summary.bonto.run/manage  
**GitHub**：https://github.com/yt9708/exec-weekly-summary  

**状态**：Demo MVP · 数据为 Mock 模拟 · 部署于 Bonto 免费版

---

### 项目结构

```
docs/     → 产品文档（PRD、需求、决策）
assets/   → 素材（设计稿、Bug 截图、参考图）
notes/    → 学习笔记（踩坑记录、技术方案）
src/      → 全部代码
```

详见 `AGENTS.md` 和 `docs/` 下的文档。

### 快速启动

```bash
cd src
npm install
npm start
```
